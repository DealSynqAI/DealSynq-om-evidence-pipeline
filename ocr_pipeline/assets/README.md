# Geographic reference asset

`cb_2025_us_state_5m.zip` is the US Census Bureau's 2025 State and Equivalent Entities cartographic boundary KML archive, downloaded from:

https://www2.census.gov/geo/tiger/GENZ2025/kml/cb_2025_us_state_5m.zip

The map-binding code uses it as an offline, reusable geographic reference for conterminous-US state maps. It does not contain any source PDF or page-specific allocation values. A rendered map must pass registration and mark-ownership checks before the atlas can supply interpreted state names. Insets and other geographies are not forced into the mainland fit.
